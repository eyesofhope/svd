# SVD Knowledge Graph Vault

Generated by `graphify` from `app/src/main/java` (1,773 nodes, 2,395 edges, 160 communities).

## Open as a vault

1. Obsidian → **Open folder as vault** → select this `obsidian/` folder.
2. Open **Graph view** — nodes auto-color by community.
3. Open `graph.canvas` — structured layout with communities as groups.

## How it's organized

- `_COMMUNITY_<Label>.md` — overview note per community: cohesion score, member list, Dataview query.
- `<NodeName>.md` — one note per code symbol (class, function, file). Contains source location, connections, tags.
- `graph.canvas` — Obsidian Canvas file laying out communities visually.

## Tags

Every note is tagged with:

- `#graphify/code` (or `#graphify/document`, etc.) — node type
- `#graphify/EXTRACTED` / `#graphify/INFERRED` / `#graphify/AMBIGUOUS` — confidence of relationships
- `#community/<Community_Label>` — which community it belongs to

## Useful Dataview snippets

Once the **Dataview** plugin is enabled:

List all symbols in a single source file:

```dataview
TABLE community, type FROM ""
WHERE source_file = "util/CookieUtils.kt"
SORT file.name ASC
```

Show every god node (high connection count) — recreate from `GRAPH_REPORT.md`:

```dataview
LIST FROM #graphify/code
WHERE contains(file.name, "VideoTaskItem") OR contains(file.name, "SharedPrefHelper")
```

## Refresh

When source code changes, rerun `/graphify app/src/main/java --update` from the project root, then re-export this vault.
